## Featured projects

### Student Management System
A school management application covering authentication, roles, students, academic management, grading, reports, and administrative workflows.

**Stack:** React, TypeScript, Vite, Firebase, Firestore, Express, Tailwind CSS

### Digital Ceremony Platform
A private-by-link ceremony platform where guests can leave wishes, signatures, and photos, with administration and downloadable memory packages.

**Stack:** Next.js, React, TypeScript, Supabase, PostgreSQL, Tailwind CSS, PDF-lib, JSZip

### Hirearky Frontend Redesign
A modern frontend redesign built with responsive layouts, motion, GSAP, and 3D web experiences.

**Stack:** React, TypeScript, Vite, Tailwind CSS, GSAP, Three.js, React Three Fiber, Lenis

## Run locally

### Prerequisites

- Node.js 20+
- npm

### Installation

```bash
npm install
npm run dev
```

Create a `.env.local` file when environment variables are required by the current application configuration. Never commit API keys or other secrets.
