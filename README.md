## Running locally

### Prerequisites

- Node.js 20+
- npm

### Installation

```bash
npm install
npm run dev
```

Create a `.env.local` file when environment variables are required by the current application configuration. Never commit API keys or other secrets.

Build for production with:

```bash
npm run build
```

## Deployment

The portfolio is deployed on Vercel.

**Live:** https://haile-portfolio-theta.vercel.app/

## Project structure

- `src/` - application source code
- `public/` - static assets
- `server.ts` - server-side functionality
- `package.json` - dependencies and scripts
- `vite.config.ts` - Vite configuration
- `tsconfig.json` - TypeScript configuration

## Security

- Keep API keys and credentials in local environment variables.
- Never commit `.env.local` or private credentials.
- Do not expose server-only secrets through client-side environment variables.
